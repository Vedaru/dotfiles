# dotfiles

My Linux desktop configuration files.

## Structure

```
dotfiles/
├── hypr/       # Hyprland (window manager)
├── waybar/     # Waybar (status bar)
├── rofi/       # Rofi (app launcher)
├── nvim/       # Neovim (editor)
└── versions.md # Version manifest
```

## System

- **OS:** Ubuntu 26.04 LTS
- **Kernel:** 7.0.12-aw88399
- **WM:** Hyprland 0.56.2
